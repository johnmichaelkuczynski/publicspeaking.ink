---
name: Course navigation
description: User requirement for uninterrupted forward navigation through the course.
---

Users must be able to go directly from a unit or subunit to the next using an arrow, without returning to a unit overview.

**Why:** The user explicitly rejects having to use “Back to Unit” to reach the next part of the course.

**How to apply:** Preserve direct sequential navigation when changing course pages, including transitions across unit boundaries. Do not introduce completion requirements for navigation.
